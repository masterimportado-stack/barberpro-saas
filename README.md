# BarberPro SaaS

Sistema SaaS para gestão de barbearias.

## Arquitetura inicial

- Backend: NestJS + Prisma + PostgreSQL
- Frontend: Next.js + TypeScript
- Cache: Redis
- Monorepo: Turborepo
